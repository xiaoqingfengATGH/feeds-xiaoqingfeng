HomePublish · 家庭服务直连发布

交互设计原型 · 所有数据与操作为本地模拟，不连接设备、不开放端口。现有 LuCI 的 Start / Apply 仍禁用；下方同名按钮仅供未来 UE 演示。
整体发布状态
先配置再保存；保存不会启动或生效。

发布概况

本机运行 / TLS
域名与证书
ACME 候选元数据（示例）；DNS、实际证书加载均未验证。
入口与公网
IPv4 / IPv6 连通性未验证；防火墙 / UPnP 适配尚未接入，未开放、未创建映射。
发布策略

服务配置

每个域名对应一个服务；全部服务共享一代专用 Nginx。禁用 / 删除先改变配置，保存后仍需整代应用；紧急撤销请停止全部。

服务 / 域名后端 URL证书配置 / 运行操作

还没有服务。添加域名、家庭后端与证书后保存，再明确启动；不会扫描或自动发布。

接入设置

作用于整个发布组，不是单个服务；保存不会开放防火墙、改 DNS 或配置上级路由。

旁路由先在主路由人工转发；这里不执行映射。
IPv6 不使用 DNAT；与后端地址族独立。
实现时拆成接口和防火墙区域选择器；授权须绑定精确范围。
IPv6 对外端口始终与内网端口相同。
1–1440 分钟；Save / Apply / 恢复不延长已建立的截止。更改活动发布策略需结束旧发布，再确认新的发布。
默认关闭 · 当前生产尚未接入；手动停止锁存优先。

诊断

按配置 → 本机 → DNS / 证书 → 入口 → 公网分层；不把本机运行当作公网成功。

配置与整代替换详情

内部 generation / revision / guard 证据属于实现诊断，原型不生成虚假证据。

失败与清理详情

无模拟故障。

静态上级转发由用户维护。未确认的自有规则 / 映射 / 快照残留必须独立列出，不能宣称全部清理。

证书引用与能力边界

复用 HomeVPN 的 ACME domain + RSA / ECC 选择身份。home.iwonderful.top 有两张候选证书（示例日期）；默认 RSA，ECC 可选但本原型不会加载。无路径输入、私钥上传或真实证书读取。

服务编辑

每个服务一个域名，不含协议、端口或通配符。
沿用 HomeVPN 证书身份选择；只存域名 + 算法引用，不读取私钥。
首版仅 HTTP 根地址；IPv6 用 http://[地址]:端口。HTTPS / 子路径不在现有范围。
高级后端设置
备用后端暂不展开；未来选择不得重放写请求。
已确认服务自身有登录 / 权限控制

确认共用的入口与策略

新增服务复用整个发布组的入口和策略。修改它们请先保存服务草稿，再到“接入设置”；不会新增第二个运行组。
