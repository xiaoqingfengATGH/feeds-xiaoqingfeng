# 首次引导 + 日常列表

## 设计立场
新增使用三步向导：服务与证书 → 共用入口确认 → 检查与草稿；现有服务编辑仍是直接表单。

## 关键选择
- OpenWrt / LuCI 简洁壳、普通表格、原生控件与克制提示，不做 SaaS 仪表盘。
- 中文导航四层：概览、服务配置、接入设置、诊断；内部证据默认折叠。
- 运行状态与配置状态独立，顶部 Start / Apply / Stop 是整个发布组的操作。
- ACME 证书按域名 + RSA / ECC 选择；RSA 默认，两项 home.iwonderful.top 候选日期均为示例，不读取真实证书。
- 无 CDN、构建、fetch / XHR / RPC、网络写入、私钥上传或设备操作。

## 取舍
- 强项：第一次理解“服务—共享入口—保存—明确开启”的顺序，避免把保存当发布。
- 弱项：新增多两次点击；共用入口仍需独立编辑，不能假装每个服务独立接入。
- 最适合：首次接触直连发布的用户；可作为方案 A 的可选新增引导。

## 打开与体验
直接双击本目录 `index.html`，无需启动应用或服务。
1. “原型演示工具”切到首次空列表，新增服务；勾选业务鉴权，再提交草稿。
2. 保存：观察仍为停止且已保存待应用；启动按钮为模拟的未来 UE，不表示当前 LuCI 上线。
3. 启动确认 → 修改后端为 `http://192.168.1.10:9090` → 保存 → Apply 差异确认，注意全服务短暂停机。
4. 接入设置切临时，停止旧发布后重新启动；再次修改、保存、Apply，截止时间不变。
5. 体验部分失败、清理未确认、空状态；清理未确认时启动禁用。
6. 375px 窄屏仅表格容器横向滚动；编辑对话框可上下滚动、Escape 取消。

完整交互规范与验证记录见 `../UE.md`。示例仅一域名，新增相同域名会报告冲突；新域名需要匹配的 ACME 证书，不做假匹配。
