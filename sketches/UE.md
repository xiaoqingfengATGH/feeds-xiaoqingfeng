# HomePublish LuCI UE 规格（仅设计）

## 结论与范围
推荐 A 原生 LuCI 服务列表 + 编辑对话框。B 只改变新增任务的组织：引导式三步新增、成熟操作仍用列表。两种方案不是配色变体，分别优化日常编辑与首次理解。

只写本 sketches 目录设计 HTML / README / 本规格。未修改应用源码、包、后端、设备或网络；无提交、部署、push、merge 或 PR。当前 UI Start / Apply 禁用，原型可点击的是未来设计按钮，均标“原型”。设计基于只读 overview.js、settings.js、product.js 与 docs/homepublish-product-design.md 当前简化架构说明；不采用已被替代的 guardian 要求。

## 信息架构与字段分层
| 页面 / 层 | 内容 | 不默认呈现 |
|---|---|---|
| 全局状态 | 发布运行状态、草稿 / 已保存待应用、长期 / 原临时截止、启动 / 应用 / 停止全部 | 内部 generation、revision JSON |
| 概览 | 本机与 TLS、DNS / 证书、入口 / 公网分层；管理服务导航 | 多段内部诊断文本 |
| 服务配置 | 域名服务列表、名称、后端 URL、证书身份、配置启用与运行快照区分 | 行级独立 Stop |
| 服务表单 | 名称、域名、ACME 域名 + 算法 + 到期、HTTP 后端、鉴权、参与下次发布 | 任意证书路径、私钥上传、内部服务标识 |
| 高级字段 | 家庭允许网段、后端 IPv4 优先 / 明确 IPv6 | 请求级重试、任意扫描、自动鉴权绕过 |
| 接入设置 | 全组 IPv4 固定转发 / 禁用、IPv6 直接 / 禁用、精确监听地址、接口 / 区域、内外端口、长期 / 临时、默认关闭开机恢复 | UPnP / STUN 伪成功开关 |
| 诊断 | 配置差异、失败阶段、自有清理残留、实际能力边界（折叠） | 未获得的 guard 或公网证据 |

表单的后端 URL 是用户表达，不意味着 canonical 接受任意 URL。未来必须拆成协议、host、port，首版只 HTTP 根地址，不支持 HTTPS upstream / 子路径 / 凭据；IPv6 要方括号，地址必须在明确审核的家庭范围。原型只做基础格式与证书域名 / 重复域名 / 鉴权提示，不代替后端安全验证。接口 / 区域在原型合并一字段示意，真实 LuCI 应为两个受限选择器。

发布策略目前是整个运行组级，不放进每行造成独立生命周期错觉。证书候选 home.iwonderful.top RSA / ECC 的日期是公开示例，沿用 HomeVPN 选择身份；RSA 默认，ECC 只演示选择，不授权真实使用或读取。示例 inventory 未包含其他域名，新域名会提示无匹配证书。

## 双轴状态机
配置轴：已保存 → 编辑为未保存 → Save 为已保存待应用 → 明确 Apply 后配置与运行一致。
运行轴：停止 → 明确 Start 已保存配置 → 全服务校验 / 启动 → 本机运行；Apply 整代短暂停机替换；任一服务就绪失败 → 部分检查失败、整代安全关闭；Stop → 持久撤意图 / 手动停止锁存 → 全组关闭 → 清理完成或清理未确认。

配置 enabled 是下一次发布的配置，不是立即启动 / 停止一行。Save 时旧快照继续运行，未保存草稿阻止 Start / Apply 并提示先保存；Stop 不需先保存，以安全撤销为优先。Stop 后 Save、恢复、重启均不解除锁存；只有重新明确 Start 并重新校验可解除。清理未确认禁止启动 / 危险端口复用；诊断区保持失败信息。

临时发布首次批准建立截止；Save / Apply / 恢复不续时。活动策略或时长变化要求先结束旧发布并另行确认，不偷偷延长旧发布。原型测试对比 deadline 不变，不是真实时钟控制器，也不承诺强实时切断。当前架构是 procd + 专用 Nginx 的整代运行组，不承诺每行独立 Stop 或不中断其他服务。

## 按钮契约
| 按钮 | 前置条件 / 确认 | 结果 |
|---|---|---|
| 新增 / 编辑 | A 对话框；B 新增三步，现有编辑直接表单 | 提交到未保存草稿，不隐式 Save |
| 只读预检 | 当前草稿基础校验 | 通过 / 阻塞提示；不网络探测、不开端口、不保存 |
| 保存配置 | 字段有效；空服务列表允许保存但不可启动 | 本应用配置提交；不启动、不重载、不全局 Apply、不开防火墙、不映射 |
| 撤销未保存修改 | 有草稿 | 恢复已保存配置，不撤销已保存 pending |
| Start（原型） | 无 draft、有已启用 saved、无清理 unknown | 确认所有服务 / 入口 / 端口 / 策略，使用 saved，解除锁存；仅模拟 |
| Apply（原型） | 运行、有 pending、无 draft；临时策略变化不走续时 | 确认新增 / 修改前后值 / 移除及全组影响；短暂停机整代替换，期限不变 |
| Stop 全部（原型） | 当前运行或失败 / unknown | 简洁确认全部服务、连接关闭与上级静态转发保留；先撤意图，清理另报 |
| 删除 | 显示目标域名与运行影响 | 仅删除草稿；Save 后仍旧快照，Apply 移除且中断全组；紧急撤销用 Stop 全部 |
| 原型场景切换 | 单独折叠演示工具，非产品按钮 | 重置示例状态，非实际观测 |

确认对话框必须说明具体新增 / 修改 / 移除、当前全服务影响、精确 IPv4 / IPv6 入口与端口 / interface / zone、策略及截止。未来真实启动才涉及明确授权的精确 INPUT 与接入操作，本原型绝不执行。Apply 失败可以保留仍合法旧代或安全关闭；本轮演示选择后者，不能显示服务部分成功仍全组运行。

## 结果证据与反馈
- 本机运行 / TLS 健康只可在原型显示为“模拟”；DNS、实际证书加载、公网入口分别未验证。
- “拟访问地址”不是已公网可达链接。IPv4 / IPv6 对外可达性均未验证，不触发导航到业务网站。
- 防火墙 / UPnP 未接入，不出现已开放、已映射。IPv4 固定转发需上级人工维护；IPv6 是路由与入站许可，不 DNAT。
- 错误就地红色文字 role=alert；全局结果 aria-live=polite，基础错误不关闭编辑器。
- 原型有域名重复 / 无匹配证书 / HTTP URL / 鉴权错误、空列表、部分检查失败、清理未知场景。
- 未来 Save 提交成功但状态读回失败必须标“已提交，状态未知”，不能误报保存失败后盲重试；原型不假造此真实 RPC 事务。

## 键盘、窄屏与防误触
使用原生 button、label、select、dialog、details；键盘 Tab 顺序与 DOM 一致，焦点明显，dialog 打开聚焦名称，Escape 取消，关闭回到触发控件。表单 Enter 提交到草稿，仍不启动。确认与取消分开，危险操作非默认保存组合按钮。375px 表单改纵向，dialog max-height 可上下滚动；table 固定最小宽度仅外层 overflow-x，页面不水平滚。此轮实际验证 DOM 布局，不声称视觉审稿已完成。

## 首次与日常任务
首次：空状态 → 添加服务 / B 向导 → 域名与匹配证书 / 家庭 HTTP 后端 / 鉴权 → 共用接入与策略 → 基础预检 → Save → 明确 Start 全组 → 分层结果未公网验证。
日常：列表编辑 → 草稿 → Save（旧流量不变）→ Apply 展示具体差异 / 全组中断 → 本机运行模拟。紧急撤销始终顶部 Stop 全部，不在行上放假独立 Stop。
